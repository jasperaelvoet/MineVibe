:::caution[Pre-alpha: under construction]
There is no release and nothing to download yet. From the source you can already boot straight into a hardcore
world, die into the next one, meet a scripted crew, and see the starter office. Most other parts are **built
separately** (agent brains, PCs, Codex, Calendar, Meetings, the app shell) and are being wired into one running

:::

## What MineVibe is

You open `MineVibe.app` and you are standing in a Minecraft world with **hardcore survival** rules.
There is no title screen, no multiplayer and no menu to quit to: the app is either open (you are in) or closed (you are out).

<CardGrid stagger>
	<Card title="A crew of Claude agents" icon="rocket">
		Embodied Claude Code agents live in the world with real health and hunger. The first one, the
		**CEO**, listens to you and can hire more agents once you approve.
	</Card>
	<Card title="Real computers in the world" icon="laptop">
		In-game PCs are real sandboxes: Linux containers or macOS VMs. Their screens render live on the
		monitors. You, or an agent, sit down and drive them with mouse and keyboard.
	</Card>
	<Card title="Talk in chat" icon="comment">
		Agents speak in bubbles above their heads. You answer in normal chat: `@ada` reaches Ada, a
		message with no mention reaches everyone. Agents with a question walk over to you.
	</Card>
	<Card title="Hardcore, with memory" icon="warning">
		If you die, the world and its crew end and a new world begins. Your machines, the Vault (your
		mounted folders) and the shared Codex survive.
	</Card>
	<Card title="Codex, Calendar, Meetings" icon="open-book">
		A shared library where agents leave notes for each other, a calendar for scheduled work, and
		meetings that gather the whole crew around a table.
	</Card>
	<Card title="Runs on your Mac" icon="star">
		Agents, game, world and PCs all run locally. Agents use your own `claude` login through the
		Claude Agent SDK. Minecraft and the mods are downloaded, never shipped.
	</Card>
</CardGrid>

## Status

"Built" means the code is in the repository and tested on its own side; "wiring" means the Node and mod halves
are being connected into one running app.

| Milestone | Scope | Status |
| --- | --- | --- |
| M0 | Foundations, monorepo, CI and docs, spikes | Done, except spike S6 (Lume), which comes before M9 |
| M1 | Bridge, boot straight into the world, Node launcher, mods installer | Done: `npm run dev` and `npm run play` |
| M2 | CEO body, reflexes, bubbles, AgentScreen (scripted brain) | Built: bodies, reflexes and every skill in the mod; the in-game UI runs against a scripted, zero-token crew |
| M3 | Wandering brain, `@` chat routing, question cards, agents walking over to ask | Built: the brain runtime, `mc` tools, chat routing and the approach queue; wiring |
| M4 | Linux PCs, sitting at a PC, PC config, budget, Vault | Built: the PC manager (Node) and the PC blocks, monitors and screens (mod); wiring |
| M5 | Agents at PCs: desk sessions (one per agent and PC), PC tools, plan approval, kicking | Built in the brain runtime and the mod's seats; wiring |
| M6 | Crew: hiring, care reflexes, usage limits, roles | Built: hire cards, care reflexes, usage governor; wiring |
| M7 | Codex, Calendar, Meetings | Built: the services (Node) and the blocks, screens and starter office (mod); wiring |
| M8 | Hardcore loop: graves, diaries, succession, new worlds | Partly: graves and death into the next world work; diaries, succession and the Chronicle are built in the brain runtime; wiring |
| M9 | macOS PCs | Planned |
| M10 | `MineVibe.app` bundle and first-run window | Partly: the Swift stub, the bundle build and its CI job; first-run setup and the startup reaper are in progress |
| M11 | Polish, soak test, Microsoft sign-in, binary releases | Planned |
